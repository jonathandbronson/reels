# reel-studio

Animated, narrated vertical reels made by Claude Code, with no filming. Every scene is HTML
animated with GSAP and rendered to MP4 by [HyperFrames](https://github.com/heygen-com/hyperframes),
3D shots are built and animated in code with Blender (`bpy`), and narration is generated by
ElevenLabs or a free local voice.

It is a standalone project.

## Setup

```bash
cd reel-studio
./setup.sh
```

This installs the HyperFrames CLI and GSAP (npm), the Kokoro local voice and Blender as a Python
module (pip), and the HyperFrames skills for Claude Code. It needs Node 22+, Python 3.11+ and ffmpeg.

## Make a reel

Ask Claude Code: *"make a reel about how the SS United States went down"*. `CLAUDE.md` holds
the steps it follows. To run them by hand:

```bash
tools/new-reel.sh my-reel               # scaffold reels/my-reel
$EDITOR reels/my-reel/script.md          # one narration line per scene
python3 tools/voice.py reels/my-reel     # voice + timing.json
python3 tools/blender/liner.py reels/my-reel/assets/blender/liner.mp4   # optional 3D shot
tools/sfx.sh reels/my-reel/assets/source/sounds                        # whoosh + hit
# write compositions/*.html and index.html from timing.json, then:
cd reels/my-reel && npx hyperframes check && npx hyperframes render -o renders/my-reel.mp4
cd ../.. && tools/sync-check.sh reels/my-reel/renders/my-reel.mp4
```

`reels/liner-demo` is a complete 11-second example.

## Pieces and what they replace from the original workflow

| Step | Tool | Notes |
| --- | --- | --- |
| Script + scenes | Claude Code + HyperFrames skills | `CLAUDE.md` |
| Voice | ElevenLabs, or Kokoro (local) | `tools/voice.py`; set `ELEVENLABS_API_KEY` for ElevenLabs |
| 3D | Blender via `bpy` | `tools/blender/` |
| Sound effects | Openverse (CC-licensed), or synthesized | `tools/sfx.sh` |
| Audio/cut sync | `hyperframes audio` + ffmpeg cut detection | `tools/sync-check.sh` |

## ElevenLabs and Openverse in Claude Code cloud sessions

Cloud environments block hosts that aren't allowed. To use them, add `api.elevenlabs.io` and
`api.openverse.org` to the environment's allowed hosts, and save the ElevenLabs key as a network
secret for `api.elevenlabs.io` (header `xi-api-key`), or export `ELEVENLABS_API_KEY` locally.
